# GreenKart Checkout Domain

Small checkout-domain module for the GreenKart ecommerce flow.

## Covered Flow

1. Add Brocolli, Cauliflower, and Cucumber to cart.
2. Review checkout rows with quantity, unit price, and line total.
3. Validate country and terms before order placement.
4. Create a confirmed order payload with item count, subtotal, and confirmation message.

## Run Tests

```bash
npm test --prefix greencart-checkout
```
